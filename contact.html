Race directors: If you would like your event to be listed, email the following information to info@svrunningcalendar.com.

  • race name
  • description
  • time and date (including day of week)
  • location (and any related details)
  • external links, if desired, such as event website, online registration, results, etc.

Alternatively, you can send me a link to a webpage that already contains all the information you’d like listed. For recurring events, I can reuse your previous listing with the date adjusted.
